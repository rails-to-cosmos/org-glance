#+TITLE: Immutable headline versions
#+DATE: 2026-10-05
#+STATUS: partial

* Contract

Org-glance and Glance share schema-1 immutable version metadata under
=data/HH/ID/versions/VERSION-ID/=.  A snapshot carries =data.org= and
=meta.json=; a tombstone carries metadata alone.  Parent references derive the
leaf set without a tracked mutable pointer.  UUIDv7 names ordinary versions;
UUIDv5 over logical id and content digest names migration roots.

* Implemented

=org-glance-version.el= writes and reads the shared metadata, publishes complete
version directories atomically, verifies the portable field shapes, and derives
leaves.  Contract tests cover snapshots, concurrent leaves, tombstones, and
deterministic migration ids.  The module is loaded by the graph but does not yet
redirect graph or material writes.

Legacy =data.org= now reads as a deterministic implicit snapshot root in the
version contract.  A stored child that names that UUIDv5 root becomes the sole
leaf while the compatibility file remains in place.

* Remaining coordinated switch

Migrate legacy blobs deterministically and update material saves so they create
children instead of mutating a leaf.  Glance must
switch its reader, writer, composite row identity, and variant UI in the same
compatibility stage.  Until then =data.org= stays canonical, preserving current
org-glance behavior and preventing a mixed-writer store.
