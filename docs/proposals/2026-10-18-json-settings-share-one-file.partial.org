* Shared protocol

- One selected tree owns =.org-glance/config.json=; format is 1.
- Absence has revision nil; existing files use SHA-256 of exact bytes.
- A writer atomically creates =config.json.lock= beside the file. Existing
  locks fail immediately. Both runtimes hold it through read, revision check,
  candidate validation and rename; cleanup runs on ordinary unwinding.
- A killed writer can leave an orphan lock. Reads continue; writers refuse.
  Stop/verify owners before explicitly recovering it. No timeout steals locks.
- Control-directory and file symlinks are refused; a selected root alias is
  canonicalized. This protects admission under cooperative writers; it does
  not defend against a hostile same-user process replacing directories.
- The temporary file is fsynced before rename. Directory fsync and power-loss
  recovery are outside the Emacs primitive's guarantee and remain a review limit.
