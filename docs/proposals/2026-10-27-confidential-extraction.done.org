#+TITLE: Confidential property extraction
#+DATE: 2026-10-27

* Contract

Existing extract commands retain their names and keys.  Every body =KEY: value=
property uses the same confidential copy operation, including ordinary text.
The selected value remains the helper API's return value.

Sealed content prompts before property selection and decrypts only in a
temporary Org buffer.  Material extraction reads current edits without
modifying the source buffer.  The table retains its property-index path for
ordinary headlines and opens encrypted content explicitly.

* Clipboard adapters

[[file:../../src/view/org-glance-clipboard.el][org-glance-clipboard]] owns the
API and acknowledged process transport; platform adapters load on demand.
The default lease is 15 seconds and must remain positive.

- [[file:../../src/view/org-glance-clipboard-linux-x.el][Linux X11]] starts an
  independent Xlib selection owner with a locked anonymous source buffer;
  XCB's raw socket interface sends payloads directly from that buffer.
- [[file:../../src/view/org-glance-clipboard-linux-wayland.el][Linux Wayland]]
  starts a memory-only data-control client.  Publication requires the compositor
  to report the helper's unique offer as selected.
- [[file:../../src/view/org-glance-clipboard-osx.el][macOS]] starts a JXA publisher
  and guardian.  Both check a sleep-inclusive clock and expire leased text
  through an ownership-conditional AppKit write.  A concurrent replacement
  causes the write to fail; nonsecret lease metadata remains.  Either process
  can expire the text after its counterpart exits.

Linux helpers check their deadlines before each transfer, disable core dumps,
refuse failed source-buffer locking, and create no payload files.  Helpers receive
plaintext through stdin and suppress diagnostics.  Confidentiality hints are
published with the content; macOS also requests =currentHostOnly=.

* Limits

Ordinary =C-y= can import clipboard text into the kill ring.  The confidential
paste command inserts directly; destination undo and save policies still apply.
Clipboard history tools must honor confidentiality hints.  Previously delivered
copies remain outside the lease, including copies materialized by macOS's
pasteboard server.  Stopping both macOS helpers can delay cleanup.  Host memory
persistence policy governs Emacs and other applications.  Native macOS tests
for expiry, helper termination and concurrent replacements require a Mac.

The shared clipboard does not authenticate the eventual destination value.
Destination-specific transfer can avoid that substitution boundary.

[[file:2026-10-27-windows-confidential-clipboard.proposed.org][Windows support]]
is deferred pending a native clipboard helper and Windows verification.
[[file:2026-10-27-confidential-clipboard-lifecycle.done.org][Lifecycle hardening]]
records the filesystem, paste, acknowledgment and deadline corrections.

* Evidence

[[file:../../test/test-clipboard.el][Extraction tests]] cover plaintext retention,
password ordering, wrong passwords, encrypted table extraction, preservation
of unsaved material edits, selection ownership, helper transport and failures.
The warm table contract requires zero blob reads and parses.
