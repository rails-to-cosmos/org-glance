#+DATE: 2026-10-25
#+STATUS: done

* Contract
The writer pins exact source bytes and the expected SHA-256 revision, then runs
the callback, envelope validation, encoding and strict decoding before acquiring
=config.json.lock=. Known busy and stale requests refuse before the callback.
The locked transaction rechecks path safety and the exact current revision for
changed, no-op and absent-file saves. A peer change refuses publication without
retry or rebase; the callback may already have run. Malformed current bytes keep
their syntax error precedence. Atomic replacement, file fsync, permissions and
cancellation cleanup retain the existing owner and lock through publication.

* Validation gate
Require compiled focused/full/shared-vector tests, cross-client process checks,
old-writer controls, paired changed/no-op/stale costs, larger configurations,
lock-tenure work and real competing-process admission. Record allocation object
counters, CPU/RSS and maximum measured-loop GC pause with generation/scope limits.
Independent review and the Glance save-pipeline proposal own the commit gate.
