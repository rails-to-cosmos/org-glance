#+TITLE: org-glance
#+AUTHOR: Dmitry Akatov

org-glance is a metadata layer, query engine, and keyboard-driven Emacs UI for
[[https://orgmode.org/][Org]] headlines. Org files remain the source of truth; indexes and views are
derived and rebuildable.

* Install

Add the package archives and install with =use-package=:

#+begin_src emacs-lisp
(add-to-list 'package-archives
             '("rails-to-cosmos" . "https://rails-to-cosmos.github.io/elpa/"))
(add-to-list 'package-archives
             '("melpa" . "https://melpa.org/packages/"))

(use-package org-glance
  :bind (("C-x j" . org-glance-transient))
  :config (org-glance-init)
  :ensure t)
#+end_src

The =rails-to-cosmos= archive supplies =org-glance= and
[[https://github.com/rails-to-cosmos/table-view][table-view]]. MELPA supplies the remaining dependencies.

* Try it

Press =C-x j +=, choose a tag, and capture an ordinary Org headline:

#+begin_src org
,* TODO [#A] Order coffee :errands:
SCHEDULED: <2026-09-23 Wed>

Try the Ethiopian roast.
#+end_src

Finish with =C-c C-c=. Press =C-x j o= and choose =errands= to open its table:

#+begin_example
| State | Title        | Scheduled       | Pri | Tags    |
|-------+--------------+-----------------+-----+---------|
| TODO  | Order coffee | <2026-09-23 Wed> | A   | errands |
#+end_example

The main actions work on the row at point or on rows selected with =m=:

| Key               | Action                                      |
|-------------------+---------------------------------------------|
| =RET=             | open the headline in a normal Org buffer    |
| =m= / =u=         | mark / unmark                               |
| =C-c C-t=         | change TODO state                           |
| =C-c C-s= / =C-c C-d= | schedule / set a deadline            |
| =+= / =-=         | capture / remove the view's tag             |
| =:=               | add a tag; =C-u := removes one              |
| =@=               | open related headlines                     |
| =i=               | edit the current cell                      |
| =/=               | filter the visible rows                    |
| =O=               | switch between table and Org overview      |
| =?=               | show the complete key legend               |

* Relations

Type =@= at the start of a word while capturing or editing to link another
headline. =C-u @= asks for the relation kind first, then the headline:

#+begin_src org
roasted by [[glance:0e904834?kind=roasted-by][Manhattan Coffee Roasters]]
#+end_src

org-glance indexes the link as a typed edge and can show it as a table column.

* Customize

#+begin_src emacs-lisp
(setq org-glance-overview-default-view 'org-glance-overview
      org-glance-filter-spec nil
      org-glance-repeat-history-depth 365)
#+end_src

- =org-glance-overview-default-view= chooses the table or Org-text overview.
- =org-glance-filter-spec= sets the filter applied to every view.
- =org-glance-repeat-history-depth= controls retained occurrence snapshots.
